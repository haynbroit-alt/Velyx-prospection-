# Glossaire

| Terme | Sens |
|-------|------|
| VELYX / VELYX Ω | l'agent économique autonome de prospection par la preuve (ce dépôt) |
| GALILÉE | moteur de découverte de lois symboliques (`haynbroit-alt/All`) |
| CORTEX | moteur de mécanismes cachés, paris à e-valeur (`haynbroit-alt/1`) |
| LAVOISIER | moteur de bilan par conservation, audit de fuites (`haynbroit-alt/A`) |
| Tr | espace commun des trois moteurs, registre et gardien (`haynbroit-alt/Tr`) |
| GARDIEN | gestionnaire de budget de tokens de l'espace commun |
| recette | ciblage écrit pour UNE demande réelle publiée ; chaque signal cite sa règle |
| signal | déclencheur public vérifiable (âge du dirigeant, immatriculation récente, RGE…) |
| pari | proposition envoyée avec critère de succès et critère d'arrêt écrits avant |
| preuve d'abord | répondre avec un échantillon réel déjà construit pour la demande |
| prive/ | dossier ignoré par git : tout ce qui nomme une personne |
| aveu | acte du registre qui consigne une limite ou une erreur |
| mandat | consigne permanente du propriétaire (ex. 0 € avant le premier encaissement) |
| SIRENE / RNE | registre officiel des entreprises (INSEE) / registre national des entreprises (INPI) |
| RGE | « reconnu garant de l'environnement », qualification de travaux de rénovation énergétique |
| décennale | assurance de responsabilité décennale, obligatoire à l'ouverture de tout chantier (C. assurances L241-1) |
